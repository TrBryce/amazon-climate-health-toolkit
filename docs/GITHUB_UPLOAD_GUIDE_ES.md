# Guía breve para publicar este proyecto en GitHub

## 1. Crear el repositorio

1. En el panel principal de GitHub, selecciona el símbolo **+** de la esquina superior derecha.
2. Selecciona **New repository**.
3. Escribe como nombre: `amazon-climate-health-toolkit`.
4. En la descripción, pega: `Open-source toolkit for harmonizing climate, environment and health data in the Peruvian Amazon.`
5. Selecciona **Public**.
6. No marques la opción para crear otro README, porque este proyecto ya incluye uno.
7. Selecciona **Create repository**.

## 2. Subir los archivos

1. Descomprime el archivo ZIP recibido.
2. En el repositorio vacío, selecciona el enlace **uploading an existing file**.
3. Abre la carpeta descomprimida `amazon-climate-health-toolkit`.
4. Arrastra **todo su contenido** al área de carga de GitHub. No arrastres el ZIP sin descomprimir.
5. En **Commit changes**, escribe: `Initial release: Amazon climate-health data harmonization toolkit`.
6. Selecciona el botón **Commit changes**.

## 3. Publicar la herramienta con GitHub Pages

1. Dentro del repositorio, abre **Settings**.
2. En el menú lateral, abre **Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Selecciona la rama **main**, la carpeta **/(root)** y luego **Save**.
5. Espera unos minutos y actualiza la página. GitHub mostrará la dirección pública de la herramienta.

## 4. Enlace para la postulación

Usa preferentemente el enlace del repositorio, porque permite revisar el código, el README, el script de R y la herramienta:

`https://github.com/TrBryce/amazon-climate-health-toolkit`

También puedes agregar el enlace público de GitHub Pages en tu CV o en una descripción complementaria:

`https://trbryce.github.io/amazon-climate-health-toolkit/`

## Recomendación de seguridad

El repositorio ya contiene una base completamente sintética. No subas bases reales que incluyan nombres, DNI, direcciones, códigos que puedan identificar participantes u otros datos sensibles.
